# PROJECT CONSTITUTION - Botalin

Дата: 2026-07-11.

Этот документ обязателен для Codex, Claude Code и любых будущих агентов проекта.

## Цель проекта

Проект ищет и проверяет криптотрейдинговые стратегии с целевой доходностью более 80% годовых.

Эта цель не является разрешением принимать завышенные или подогнанные результаты. Доходность принимается только после out-of-sample проверки независимым валидатором.

## Неприкосновенные правила достоверности

- Любая заявленная доходность принимается только после out-of-sample validation.
- Комиссии, spread, slippage и funding обязательны во всех метриках, где они применимы.
- Look-ahead bias запрещен.
- Data leakage запрещена.
- Hidden dataset запрещено менять, пересоздавать, подглядывать или использовать для подгонки.
- Критерии проверки нельзя менять ради прохождения теста.
- Тесты нельзя ослаблять, удалять или переписывать так, чтобы скрыть регрессию.
- Метрики принимаются только из независимого валидатора, а не из отчета агента-исполнителя.

## Правила безопасности

- Live trading запрещен без отдельного ручного подтверждения владельца проекта.
- Real exchange keys нельзя передавать агентам, печатать в логах или читать из `.env`.
- Private keys, `.pem`, `id_rsa`, exchange secrets, deployment tokens и production env files запрещены для чтения автоматическим контуром.
- Деплой, systemd, sudo, destructive Git-команды и удаление репозитория запрещены для автоматического контура.
- Любой private API ключ должен быть минимально привилегированным, без withdrawal permission.

## Роли агентов

Codex отвечает за:

- архитектуру;
- аудит;
- приоритизацию;
- постановку задач;
- review результата;
- принятие решения ACCEPT, REVISION или REJECT;
- создание следующей задачи.

Claude Code отвечает только за:

- выполнение одной конкретной задачи;
- изменение только разрешенных файлов;
- создание или обновление тестов в рамках задачи;
- запуск разрешенных проверок;
- отчет о результате;
- commit выполненной задачи.

Claude Code не выбирает следующую задачу, не меняет критерии приемки и не расширяет scope.

## Review Protocol

Каждая работа Claude проходит через Codex review:

- проверка diff;
- проверка измененных файлов;
- проверка запрещенных файлов;
- запуск тестов из задачи;
- проверка отчета Claude;
- проверка hidden errors, leakage, cost model и security impact.

Только Codex может принять задачу.

## Trading Evidence Standard

Стратегия может считаться кандидатом только при наличии:

- immutable commit id;
- frozen config;
- train/validation/holdout split;
- OOS metrics;
- net-of-cost PnL;
- funding/spread/slippage/fee accounting;
- minimum sample size;
- drawdown and stability metrics;
- independent validator output.

Любой результат без этих признаков является исследовательским сигналом, а не доказанной стратегией.
