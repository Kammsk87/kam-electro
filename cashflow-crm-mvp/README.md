# CRM MVP для игры "Кэшфлоу"

Серверный MVP CRM для проверки бизнес-процесса: клиенты из UDS, игры, записи, отметка посещения и очередь задач для Telegram-бота.

## Запуск

```bash
cd "/Users/aleksandr/Documents/New project KAM/cashflow-crm-mvp"
/Users/aleksandr/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Открыть:

```text
http://localhost:4173
```

## Показ сотруднику в одной Wi-Fi сети

Запустить CRM с доступом по локальной сети и паролем:

```bash
cd "/Users/aleksandr/Documents/New project KAM/cashflow-crm-mvp"
HOST=0.0.0.0 CRM_USER=manager CRM_PASSWORD="your-password" /Users/aleksandr/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Узнать локальный IP Mac:

```bash
ipconfig getifaddr en0
```

Сотруднику открыть:

```text
http://ВАШ_IP:4173
```

Логин: `manager`, пароль тот, который указан в `CRM_PASSWORD`.

Не запускайте кабинет в локальную сеть без `CRM_PASSWORD`, потому что в базе есть персональные данные клиентов.

- фильтры по статусам и сегментам;
- добавление нового клиента;
- создание игр с датой, временем, местом и лимитом мест;
- запись клиента на игру;
- автоматическое создание задач "Напоминание 24ч" и "Напоминание 3ч";
- отметка "пришел / не пришел";
- автоматическая задача на повторный визит или новую дату;

## Работа менеджера

В CRM есть блок "Приглашение на игру":

- менеджер выбирает сегмент, например "Недавно посетили" или "Telegram готов";
- CRM показывает гостей из текущей выборки;
- можно выбрать первых 15 гостей или снять галочки вручную;
- после выбора игры кнопка "Поставить приглашение" создает Telegram-задачи только для отмеченных гостей;
- бот отправит приглашения тем, у кого есть `telegramChatId`.

Официальный Telegram Bot API отправляет сообщения от имени бота. Личный аккаунт менеджера можно использовать как ответственного/оператора в CRM, но не как отправителя через Bot API.

В карточке клиента есть блок "Коммуникация":

- видно, привязан ли Telegram (`telegramChatId`) или есть только username;
- можно скопировать персональную ссылку на бота;
- можно отметить, что сообщение отправлено вручную;
- можно записать ответ клиента;
- можно поставить дату следующего контакта;
- сегмент "Написать сегодня" покажет клиентов, у которых дата следующего касания наступила.

## Telegram-бот

Запуск с отправкой Telegram-сообщений:

```bash
cd "/Users/aleksandr/Documents/New project KAM/cashflow-crm-mvp"
TELEGRAM_BOT_TOKEN="123456:ABC..." /Users/aleksandr/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

Как работает очередь:

- CRM создает задачи со статусом `К отправке`;
- сервер смотрит задачи Telegram, у которых время отправки уже наступило;
- если у клиента есть `telegramChatId`, сервер отправляет сообщение через Telegram Bot API;
- после успешной отправки задача получает статус `Готово`;
- если `telegramChatId` нет, задача получает статус `Нет chat_id`.

Входящие сообщения тоже обрабатываются. Сервер использует long polling `getUpdates`, поэтому публичный webhook для локального MVP не нужен.

Команды:

- `/start` — создать или обновить клиента по Telegram username;
- `/start CL-02623` — привязать Telegram к конкретному клиенту CRM;
- `/games` — показать ближайшие игры;
- `/help` — показать команды.

Важно: Telegram-бот не может первым написать человеку по `@username`. Клиент должен сначала написать боту. После `/start CL-02623` сервер сохранит `telegramChatId`, и очередь задач сможет отправлять напоминания автоматически.

## Ограничения MVP

- база пока файловая, не PostgreSQL/Supabase;
- Instagram на первом этапе ведется вручную;
- нет авторизации пользователей CRM.
