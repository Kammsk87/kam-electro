# Берлога: база бутылок и подборка изображений v1

Файлы подготовлены как рабочий слой поверх текущего проекта `/Users/aleksandr/projects/berloga-poster`.

- `bottle_research_queue_v1.csv` — вся карта из `data/skus.csv`, разложенная по приоритетам: что уже можно готовить к публикации, где надо подтвердить наличие, где есть пробелы в данных.
- `image_candidates_v1.csv` — первая подборка источников изображений. Это не финальное разрешение на публикацию: у официальных страниц и ритейлеров нужно запросить медиакит/разрешение или использовать как ориентир для ручного выбора/съемки.

Правило: сначала official/media-kit/distributor, потом Wikimedia/Unsplash с лицензией и атрибуцией, потом собственная съемка. Картинки из случайной выдачи без источника не считаем годными для продакшена.
