# KAM Fit Coach MVP

Локальный прототип адаптивного фитнес-приложения.

## Как открыть

Откройте `index.html` в браузере.

## Что уже есть

- профиль: пол, цель, место тренировки, уровень, ограничения;
- учет менструальной фазы для женского профиля;
- путь клиента перед тренировкой: быстрый чек-ин, план, причина рекомендации, цель дня;
- локальный вход по имени и коду с отдельной историей тренировок для каждого пользователя;
- быстрые режимы: готов, устал, 25 минут, болит, кардио;
- ежедневное состояние: сон, энергия, стресс, боль, обратная связь;
- конкретные шкалы состояния с пояснением, как показатель влияет на нагрузку;
- итог прошедшей тренировки: минуты, сложность, боль после, выполненный объем, заметка;
- расчет готовности к тренировке;
- адаптивная тренировка дня для зала, дома или воркаут площадки;
- активный режим тренировки: упражнения, подходы, вес, повторы, отметка выполнения;
- принятие данных по упражнению со сворачиванием карточки и возможностью развернуть обратно;
- замена упражнения во время тренировки;
- пояснения к упражнениям и окно техники с надежными встроенными схемами выполнения;
- мобильная верстка для популярных размеров телефонов с крупными touch-полями для кг, повторов и подходов;
- Mobile Gym Mode: определение mobile/tablet/desktop, нижняя панель быстрых действий и touch-адаптация;
- адаптивный dashboard layout для laptop, desktop, tablet и mobile без пустых полей и горизонтального overflow;
- стартовый протокол тренировки: дорожка/ходьба, динамическая растяжка, затем силовой блок;
- выбор фокуса дня: авто, грудь-плечи-руки, спина-бицепс, ноги-ягодицы, кардио-растяжка;
- быстрый выбор текущей тренировки в день открытия: авто, грудь, спина, ноги, кардио, круговая;
- onboarding-ассистент при первом входе: проводит по чек-ину, профилю, состоянию, подходам, технике, сохранению и прогрессу;
- учет частоты тренировок: 2-5 дней в неделю;
- стили программы: сплит, круговые тренировки, смешанный формат;
- варианты программ на день, неделю и месяц;
- месячная логика с прогрессией 3+1 и разгрузочной неделей;
- базовые советы по питанию;
- журнал выполненных тренировок;
- локальное сохранение в браузере через `localStorage`;
- счетчики прогресса и напоминания по кардио, силовым и восстановлению.

## Следующий слой

Для полноценного продукта стоит добавить аккаунты, серверную базу, календарь, систему упражнений, медицинские ограничения, интеграцию с носимыми устройствами и отдельный модуль рекомендаций.
