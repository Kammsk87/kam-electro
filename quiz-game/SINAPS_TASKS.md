## Файл 3: `src/app/presenter/page.tsx`

### 16. Добавить обработку type:"sinaps" (fullscreen + крупный шрифт)

Текущая структура: presenter обрабатывает idle/round/question/reveal/leaderboard/final.
Синапс шлёт `{ type:"sinaps", screen:"task"|"answer", title, subtitle, body?, bullets?, answer?, teams? }`.
Сейчас эти сообщения игнорируются — зал ничего не видит.

Добавить блок после `{screen.type === "reveal" && ...}`:

```tsx
{screen.type === "sinaps" && (
  <>
    {screen.screen === "task" && (
      <div className="flex w-full flex-col items-center gap-6">
        {screen.index != null && (
          <p className="text-lg text-zinc-400">
            Задание {screen.index} из {screen.total}
          </p>
        )}
        <h1 className="text-6xl font-black leading-tight">{screen.title}</h1>
        {screen.subtitle && (
          <p className="text-2xl text-cyan-400">{screen.subtitle}</p>
        )}
        {screen.body && (
          <p className="text-2xl text-zinc-300">{screen.body}</p>
        )}
        {screen.bullets?.length > 0 && (
          <ul className="w-full max-w-3xl space-y-3 text-left">
            {screen.bullets.map((b: string, i: number) => (
              <li key={i} className="text-2xl">{b}</li>
            ))}
          </ul>
        )}
        {screen.teams && (
          <div className="w-full max-w-xl space-y-3">
            {[...screen.teams]
              .sort((a: any, b: any) => b.score - a.score)
              .map((team: any, index: number) => (
                <div key={team.name} className="flex items-center justify-between rounded-lg bg-zinc-900 px-6 py-3 text-2xl">
                  <span>{index === 0 ? "🏆 " : `${index + 1}. `}{team.name}</span>
                  <span className="font-bold text-emerald-400">{team.score}</span>
                </div>
              ))}
          </div>
        )}
      </div>
    )}
    {screen.screen === "answer" && (
      <div className="flex flex-col items-center gap-6">
        <p className="text-2xl text-zinc-400">{screen.subtitle ?? screen.title}</p>
        <h1 className="text-7xl font-black text-emerald-400">{screen.answer}</h1>
      </div>
    )}
  </>
)}
```

Также: контейнер presenter сейчас `max-w-4xl` и `p-12`.
Для fullscreen убрать отступ и ограничение ширины для sinaps-экрана.

- если `screen.type === "sinaps"` → `className="flex min-h-screen flex-col items-center justify-center bg-zinc-950 text-white"` (без padding и max-w)
- иначе — текущие классы
