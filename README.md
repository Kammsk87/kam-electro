# КАМ Электро

Статический лендинг для заявок на сборку электрощитов и электромонтаж.

## Деплой

Проект можно разместить как обычный static site: `index.html`, `styles.css`, `script.js` и папка `assets`.

### Vercel с автодеплоем

1. Создать репозиторий на GitHub.
2. Загрузить в него файлы проекта.
3. В Vercel выбрать Add New Project и импортировать GitHub-репозиторий.
4. Framework Preset: Other.
5. Build Command: оставить пустым.
6. Output Directory: оставить пустым или `./`.
7. Production Branch: `main`.

После этого каждый push в `main` будет публиковаться автоматически.

### Что заменить перед запуском

- Телефон: `+7 999 000-00-00`
- Почта: `info@example.ru`
- Название/бренд: `КАМ Электро`
- По желанию: подключить настоящую форму через CRM, Telegram или почтовый сервис.
